01

智能知识库问答系统 · Agentic RAG

主作品 · 2026.08 – 至今 · Python / FastAPI / React 19

面向企业知识管理场景的 AI 问答系统。答案带 [n] 引用、可回溯原文分片，支持分级访问控制与内容审核。

关键设计

  • 多格式文档解析 → 向量（pgvector）/ 全文（Elasticsearch IK）/ 图谱（Neo4j）三类索引。
  • 双路并行召回 → RRF 融合 → Reranker 精排；知识检索、查询改写、图谱查询、联网搜索封装为 4 个工具，由 Agent 自主选择调用。
  • 回答经 SSE 流式输出，前端实时渲染文本、工具状态与引用溯源。

可验证结果

  • 206 条离线评测集（检索 148 + 生成 58），另有 19 条图谱专项。
  • 51 条近义改写难例四级消融，hit@1：纯关键词 BM25 0.706 → + 向量召回 0.804 → + 兜底门控 0.824 → + rerank 0.941。
  • 20 并发出现 5 个失败、p50 2.5s → 31s，定位到 FastAPI 生成器依赖持有数据库会话；改短生命周期会话后100 并发零失败（单机压测、Mock 模型服务）。

已知边界：自建项目，本地 Docker Compose 运行，无真实用户、未上公网；压测为单机 Mock，不代表生产容量；查询向量落盘冻结后才消除服务端浮点非确定性带来的评测抖动。

02

自主编码 Agent 运行时 · tiny-claw

差异化作品 · 2026.06 – 2026.09 · Python / asyncio / MCP

自托管的自主编码 Agent 运行时，提供 CLI 与飞书机器人两个入口，重点解决长任务上下文超限、工具失败循环与高危操作权限三类问题。

关键设计

  • Agent Loop 自主完成推理、工具选择、结果回传与下一轮决策；工具异常转标准化错误码，不让异常中断主循环。
  • 上下文按信息价值分 6 档渐进淘汰，保护用户指令与失败记录；采用确定性淘汰、不依赖 LLM 摘要。
  • MCP 工具经适配层注册并做命名空间隔离；7 条高危命令规则命中后转飞书人工审批，超时 300s 默认拒绝。

可验证结果

  • 265 个单元测试全绿且全部离线可跑；21 个错误码 + 20 条表驱动恢复提示。
  • 每轮固定注入 Token 1818 → 1013（−44%）；以真实账单校准计量后，估算倍率偏差 3.05 → 1.34。
  • 双阶段推理对照实验：成本 +54%、耗时 +43%、通过率 4/4 vs 4/4 无差异，结论记为无提升（两次跑分非同组复跑，存在天花板效应）。

已知边界：自托管自用运行时，非通用框架；无公网 Demo，演示需本机 CLI；飞书审批需自行配置；MCP 端到端只验证过 stdio 传输。

04

开源全栈 API · leo-api

Node.js 佐证 · Express 4 / Sequelize / MySQL / Redis

leo-api 是一套基于 Node.js 的开源全栈 API，用于在本地跑通接口、数据与实时推送的后端链路。后端以 Express 4 直接依赖搭建，Sequelize 操作 MySQL，22 个迁移管理表结构演进，路由按前台、管理端与第三方入口分层；JWT 三层鉴权与 SSE 通道覆盖权限和消息推送。架构与取舍由我主导，实现含 AI 协作。项目自建开源，Docker Compose 本地启动，无自动化测试，未上生产环境。

关键设计

  • 跨进程 SSE：连接分散在多个进程时单进程广播会丢消息，故用 Redis Pub/Sub 做公共总线，配独立订阅连接、并发锁、25s 心跳与关闭清理。
  • JWT 三层鉴权：用户、管理员（role=100）与 SSE 分离，实时通道不复用高权限令牌，兼容原生 EventSource 的 ?token=。
  • 22 个迁移、10 个模型，表结构演进可版本化回放与回滚。

项目价值

  • 与 Python / FastAPI 两套 AI 项目形成 Node.js + Python 双栈证据。
  • Express 为 ~4.16.1 直接依赖，可正面说明对 Express 的熟悉程度。

已知边界：自建开源项目，Docker Compose 本地起 MySQL，无自动化测试，非生产运行，仅作本地演示与能力佐证。
